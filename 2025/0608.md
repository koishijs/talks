# Cordis Env

两个 cordis app 之间通过某种方式通信。

- webui 的前端和后端
- 运行在独立进程的 cordis 插件

显式的通信方式：

1. 服务调用（comlink：proxy + 异步化，支持回调函数等）
2. loader api（修改配置文件的能力）

```ts
ctx.webui.addEntry(entryPath, dataFactory)

ctx.webui.loader.create({
  name: entryPath,
  config: reactive(reactiveData) satisfies client.Config,
})
```

```yaml
- name: '@cordisjs/plugin-webui'
  config:
    plugins:
      # 配置文件
```

# Loader API

- Entry
- EntryGroup
- EntryTree (BaseLoader)
  - Loader API 其实是挂在这里的
  - 对内提供隔离域内的 loader 服务
- ~~Loader extends EntryTree~~
- NodeLoader extends EntryTree

```ts
ctx.plugin(NodeLoader, {
  filename: ...
})

class WebUI extends Service {
  loader: BaseLoader
  constructor(ctx: Context) {
    super(ctx)
    this.loader = new BaseLoader(ctx)
  }
}
```
